## 구조

질문이 들어와서 답이 나가기까지의 흐름입니다.

```
문서(PDF) → ingest.py → chunks.jsonl → embed.py → 임베딩 파일
질문 → search.py(top-k 검색) → ask.py(LLM 답변 + 근거) → FastAPI /ask
```

| 단계 | 파일 | 상태 |
| --- | --- | --- |
| 텍스트 추출·청크 분할 | `ingest.py` | 진행 중 (W1) |
| 임베딩 | `embed.py` | 예정 (W2) |
| 검색 | `search.py` | 예정 (W2) |
| 답변 생성 | `ask.py` | 예정 (W3) |
| API | `app.py` | 예정 (W4) |
